# Style reference (approved by the user in-game, 2026-10-11)

Kids' monster-collecting adventure (5th-graders). English should read like a well-localized 2000s kids' RPG:
light, quick, natural, never stiff; villains can be grand. Keep every bit of information; adapt idiom.

## Conventions shown above
- ・・・ / …… → "..." (attach to the word: "Oh..." / "...Partner...?"). ！？ → "!?". Interrupted word → "--".
- Kinship terms translated (兄さん = big brother); honorifics on names kept hyphenated (Hel-sama, Mirai-chan).
- Split sentences across {wait}/{page}/{f0} so each piece reads naturally in sequence, as in the JP.
- No line breaks: write each box as running text; the build wraps it. Only keep a JP {n} when it follows a
  {wait} inside the same box (a deliberate new line) or in dates/lists.
