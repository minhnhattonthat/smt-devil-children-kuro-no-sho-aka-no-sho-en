# Glossary - Shin Megami Tensei: Devil Children Black Book / Red Book (PS1)

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.

## Rulings (asked of the user 2026-10-11)
- Terms/names: MegaTen fan standard (megatenwiki / anime) first; mainline SMT official demon names; else Hepburn.
- Honorifics: kept, hyphenated (Setsuna-kun, Mirai-chan). Western order for full names (Setsuna Kai).
- Credits: English (roles translated, staff names romanized).
- Specs/engine plans: pre-approved; report results.
- Full names and terms everywhere; prefer engine work over shortening. Abbreviate only as a flagged last resort.
- No suffix glued onto a variable ("1th"); rephrase. Jokes and wordplay keep their punch.

## Style rules
- Punctuation: 「」 -> "...", 『』 -> '...', … -> ..., ！？ -> !?, full-width space between phrases -> normal space.
- Register: kids' adventure (5th-graders); light, energetic, clear.
